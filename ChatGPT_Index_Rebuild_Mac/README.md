# ChatGPT_Index_Rebuild_Mac

此脚本针对本次检查过的 Mac 数据库结构制作，是本地维护脚本，并非官方修复工具。它会让应用在下次启动时重新拉取 ChatGPT 聊天索引；无法保证修复独立的网络错误或界面转圈问题。

## 执行

1. 保存工作，使用 ⌘Q 完全退出 ChatGPT 和 Codex。执行期间不要重新打开它们。
2. 双击同目录的 `rebuild_chatgpt_index.command`。如果双击不能启动，可在普通 Terminal 中输入 `bash `，把该文件拖进终端后回车。
3. 核对显示的数据库位置和记录数量，输入 `REBUILD` 并回车。
4. 等到出现“已重置 ChatGPT 索引，并标记为需要完整重建”，保存输出的备份位置与恢复命令，然后手动启动 ChatGPT。观察列表是否重新加载，及原来已删除的聊天是否消失。

两个脚本文件必须放在同一个文件夹。不需要 sudo，不安装任何软件，不自动退出或启动应用。

## 只检查

在终端输入 `/usr/bin/python3 `，拖入 `rebuild_chatgpt_index.py`，再输入 ` --check` 并回车。只检查可以在应用运行时执行。

## 修改范围

固定目标为当前用户的 `~/.codex/sqlite/codex-dev.db`，不会搜索并修改其他数据库。

仅处理注册类型为 `chatgpt` 的账户索引：

- 清除该账户的本地列表索引行、扫描临时行与扫描检查点。
- 将该账户的同步水位清空、初始构建设为未完成、完整核对时间清空，以触发完整重建。
- 增加共享的索引版本号，使变化可被应用识别。

会处理该数据库中所有已识别的 ChatGPT 账户索引。保留账户注册、本地和远程 Codex 任务、项目及其他表；不修改登录凭证、聊天正文或云端记录，也不改网络设置。

## 安全措施

- 检查应用进程和数据库占用；无法检查、应用未退出、结构变化或完整性异常时停止。
- 通过 SQLite 备份接口生成一致的完整备份，包含已提交的 WAL 数据，并校验备份完整性。
- 备份位于脚本旁 `chatgpt-index-backups` 文件夹，使用限制当前用户访问的权限。备份含私人应用数据，请妥善保管。
- 备份成功后才修改索引。所有修改放在一个事务内；提交前验证目标状态与范围外数据。失败则回滚。
- 不直接删除或替换原数据库及其 WAL/SHM 文件。

## 恢复

先完全退出 ChatGPT/Codex，再运行成功提示中打印的恢复命令。形式如下：

```text
/usr/bin/python3 "/脚本所在目录/rebuild_chatgpt_index.py" --restore "/脚本所在目录/chatgpt-index-backups/before-rebuild-实际时间"
```

恢复会先备份当前数据库，再只恢复所选备份中的 ChatGPT 索引与扫描状态；不把整个数据库覆盖回旧版本，因此不会覆盖随后新增的其他任务。恢复会把 ChatGPT 索引带回修复前状态，旧的显示问题也可能随之返回。账户集合或数据库结构已经变化时，脚本拒绝自动恢复。

如果停止时提示数据库占用或应用仍在运行，退出相关应用后重试，不要强删锁文件。
